# Fallout 1–2 style previews

Open `index.html` to compare the two original style directions. Use its switch to view the tree or SPECIAL. `classic.html` and `pipboy.html` are standalone offline pages with saves separate from the main planner.

- A / `classic.css`: the character screen, gray metal, yellow headings, black panels and bright green text.
- B / `pipboy.css`: an olive Pip-Boy casing, rounded bezel, green CRT and softer contrast.

Both preserve the working perk tree and original illustrations. These are HTML/CSS mockups, not AI-generated images. The main planner now combines B's casing and display with A's recessed fields and mechanical keys.

`build-previews.py` replaces the main page theme with each original direction, changes the storage key and loads a sample build. `*-tree.png` and `*-special.png` are Edge screenshots at 1600 × 1000. The current combined design is shown in `../Pip-Boy-preview.png` and `../SPECIAL-preview.png`.
